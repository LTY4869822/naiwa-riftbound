# 贯穿重拳 · 第一版

入口仍为 `prototype/v6/slice.tscn`，U 在 Lv.2 解锁，消耗 60 专注；普通攻击命中积累专注。`大招试玩（不保存）.cmd` 使用隔离档案，以 Lv.3 / 100 专注开始，运行期的奖励与成长不写入真实存档。继续使用游戏内虚拟碎片卡。

## 动作和节奏

- 不新增或重绘人物图。本次只调整现有、已确认的完整侧身帧的播放时间；18 张人物 PNG 没有修改。
- 标准蓄力 0.48 秒，总动作 1.05 秒。先收拳蓄力，再前送出拳，保持命中姿势，最后收拳回到防备；0.70 秒后可闪避取消后摇。
- 接触帧为既有第 6 帧。物理移动、姿势、拳头锚点更新完成后发射一次，左右反射使用相同规则。
- 所有角色帧始终保持 0.175 等比缩放与原地面锚点。没有网格形变、局部拉伸或生成补帧。

## 战斗行为

- 拳风向面前以 1250 逻辑像素/秒移动，最远 740 像素，上下各 67 像素的扫掠判定。单波可贯穿多个目标，每个敌人只承受一次。
- 基础伤害为常规伤害 × 2.8，使用敌人的既有重击处理，能破势；飘字采用实际掉血量。没有修改其他敌人的招式或关卡。
- 前摇保护 0.62 秒；后摇存在受击风险。命中第一次目标停顿 65 毫秒，后续目标不会连续重复震屏。
- 暂停冻结拳风、粒子时间与命中判定；切回补给/桌宠取消未完成动作，重开与结算清掉旧拳风。

## 开源素材的实际用法

使用 [Effekseer / tktk vol.2](https://effekseer.github.io/zh-cn/contributes/tktk02/index.html) 的六张 CC0 原始部件贴图，在 Godot 中重新组合蓄力、光芯、破碎拖尾和命中爆裂。这里没有声称播放原生 Effekseer 效果，也没有安装 Godot 插件或改变全项目渲染器。原始字节、文件 SHA256、下载 URL 与许可证据见 `prototype/assets/ultimate/SOURCES.json`。运行时添加颜色和边缘淡出，源 PNG 不改绘。

背景折射改写自 [shizu0817/godot-shockwave-shader](https://github.com/shizu0817/godot-shockwave-shader)，保留 MIT 许可。增加像素尺寸、零距离保护、UV 限制、较弱折射和单次背景捕获。背景捕获 z=1、折射 z=2、敌人 z=3、奶娃 z=5、前景特效 z=10、HUD 为独立 CanvasLayer，人物和 HUD 不进入折射输入。

“减少动效”关闭折射和震屏，保留蓄力、方向、命中及伤害提示。三个声音由 `tools/prepare_ultimate_assets.py` 本地合成，非他人游戏提取音效。

## 验证与预览

- `--bridge-check --ultimate-check`：左右命中时序、贯穿/重复/背后目标、暂停/停顿、最大射程和低帧率扫掠、取消/清理、角色比例和存档隔离。
- `--slice-test`：既有战斗、逐帧落地和虚拟喂食流程回归。
- `--bridge-check --ultimate-review`：原生 Compatibility 渲染器截图。
- `tools/render_ultimate_film.py`：原生实战物理与渲染路径录制左右大招及减少动效版本；视频音轨按运行时检测到的蓄力、释放、命中事件混入同一组合成音效。

截图和自动检查只验证本轮功能，视觉满意度仍以实际试玩反馈为准。
