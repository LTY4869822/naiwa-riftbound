## 项目边界

沿用 Windows 桌面、Godot 4.7 Compatibility、固定正交横版战斗镜头、打怪→虚拟文件→喂食升级→返回桌宠的玩法。设计画布 1280×800，默认窗口 1152×720，最低 960×600；目标 60 fps。没有更换类型、镜头或目标平台。

奶蛙身份锁定：原版梨形身体、小头、绿色眼睛、米色腹部、短臂和三趾脚；禁止拉成长手长腿、替换面部、添加服装改变轮廓。原版桌宠是独立的用户已明确要求保留的旧资产与原生交互。游戏中的目标资产是经过原图校型的三维角色；目前只有 PNG 序列，没有原作者三维源文件。原图临时角色必须标记为过渡资产，不把图像变形或图片贴片宣称为完成三维绑定。

## 视觉命题

“温暖的黄衣旅者，穿过青色森林中的折页遗迹。” 大块明暗、清楚的姿态与精确的动作切口产生力量感。环境留下安静区域，让黄色主角、青色友方攻击和珊瑚色敌方预警突出。表面不靠噪声或泛光堆砌细节。

## 三维材质与光照

统一三档阴影：暗面 / 固有色 / 亮面。主光方向固定为左上前方，阈值 0.18 / 0.62，不对多灯结果做连续 PBR 叠加。用法线塑造明确明暗面；大面保持完整，必要时修改法线，而不是添加真实表面贴图。

| 材质 | 暗面 → 中间 → 亮面 | 表现 |
|---|---|---|
| 石材 | 暗蓝 → 森林中间色 → 远景浅青 | 大切面、少量边缘倒角；无脏污噪声 |
| 叶甲 / 树皮 | 墨线 → 森林深色 → 森林中间色 | 长弧边缘、叶脊；无照片纹理 |
| 硬质骨甲 / 纸甲 | 暗蓝 → 浅青 → 纸白 | 大块折面、有限刻线 |
| 金色核心 | 暖暗黄 → 奶蛙黄 → 奶油色 | 小面积纯色核心；不用全屏 bloom |

近景主轮廓约 1.2–1.8 px（800 高画布），中景约 0.6–1 px，远景不描边。轮廓用逆法线外壳，深度淡出，禁止所有距离一律粗黑线。面部内部线比外轮廓轻。天空与远景以实色层次建立空间，不加连续雾墙遮蔽战斗。

照明层级：主角与敌人 > 可交互道具 > 战斗地面 > 中景建筑 > 远景。接触阴影必须贴地；移动时锁住承重脚的世界坐标。装饰光不能淹没警示形状。

## 形体与角色

- 奶蛙：原版正侧面轮廓对照通过后才能替换；头宽、腹部宽、眼睛位置与腿长误差目标 ≤ 3%，禁止非等比整体缩放。保留原图作可视对照。
- 刃叶巡卫：低重心楔形头、背部三片长叶甲、四肢弯曲，前肢锋刃；读取轮廓即识别近战突进。攻击先收臂，脚站稳，再向前切出。
- 灯翅：菱形翼、细长腹、暖色小灯核；飞行不使用人类走路循环。合翼聚光→锁定方向→展开射击；弱点在恢复期。
- 折页守卫：宽肩拱背、书页形大盾、垂直裂缝核心，体型约普通敌人 1.5 倍；慢蓄力、重落地、明确破势。不得仅给普通敌人等比放大。
- 环境：大曲线树干 + 大块折页石材；前景避免遮挡角色脚和攻击预警。装饰不穿过人物所在平面。

## UI、图标与载入 / 宣传

UI 使用墨蓝底、纸白字、青色焦点、黄色主操作，直边和有限斜切。主菜单一个首要动作“出发”，背包是次级面板；不做一屏卡片仪表盘。战斗上方只放生存信息、章节与 Boss，下方放操作与技能聚能。

1280×800：标题 56–76 px，正文 22 px，次要文字 ≥ 18 px；最低窗口下重要文字 ≥ 16.5 px。交互目标设计高度 ≥ 60 px（最低窗口下 ≥ 45 px）；键盘焦点用独立高对比边框，不能只靠颜色。文字对比目标 ≥ 4.5:1；大字 ≥ 3:1。危险同时用尖角 / 条纹 / 蓄力环，友方用弧线 / 菱形。24 px 图标使用 2 px 线，保持 3 px 内边距，48 px 复用同一形状，禁止通用 emoji 混搭。

载入画面：墨蓝底、同款章节号与折页菱形进度，保留纸白文字。宣传图必须来自通过验收的三维角色与场景；可以重新布光与构图，但不得单独换成绘画写实风。截图不能被标为最终宣传资产。

## 动作与特效

模拟 60 Hz，显示跟随渲染帧； locomotion 连续插值，脚按实际位移推进步相，承重期世界坐标锁定。角色根节点负责位移，肢体不独自“跑”而根不动。空中不得套用站立脚锁。

攻击采用预备 / 出手 / 跟随 / 恢复四段；预备和恢复用缓入缓出，出手集中在 2–4 帧。关键姿态可停 2 帧，但不整段低帧率。轻击停顿 35 ms，重击 70 ms；只冻结战斗表现，不阻塞 UI。减少震动设置关闭位移震屏，保留命中形状。特效色块最多三层，尖端清晰，普通斩击 0.18–0.30 s；大招不常驻遮蔽角色。

## 禁止项

照片纹理和噪声污渍；连续油亮 PBR 高光；全屏渐变与过量泛光；远近一样粗的黑边；角色拉伸代替肢体运动；脚悬空或原地滑步；攻击特效与碰撞时间错位；每个批次换一种风格；从商业游戏挪用角色、图标或标志；把临时原图说成三维成品。
