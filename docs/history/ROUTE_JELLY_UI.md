# 四境巡游：果冻关卡地图

本次仅重做选关界面和确认反馈，沿用四张实际场景与各自的守关者、通关记录、共用成长和虚拟碎片。没有修改人物 PNG、动作、桌宠或关卡规则。

## 参考与边界

按用户指定的 [amiaoapp/inkwave](https://github.com/amiaoapp/inkwave) 读取 `styles/ui.css`、`src/ui/menus.js`、`src/ui/menu-art.js` 和 MIT 许可。SHA 与核对范围见 `../research/route-jelly-reference.json`；许可原文保留于 `prototype/assets/notices/INKWAVE-MIT.txt`。

参考源码的弹性曲线为 `cubic-bezier(.34,1.56,.64,1)`，聚焦放大 1.045 倍、按下约 0.955 倍，并包含指针原点的墨团扩散、外焦点层和分批入场。本项目用 Godot 原生 Button、弹簧积分和原创卡片 shader 重新实现，未引入网页运行时、角色、Logo 或外部游戏图片。原有的独立墨水转场继续复用。

## 当前表现

- 四张有厚边、顶缘高光和厚投影的圆角卡片，保留真正关卡背景预览。编号为各地图主题色贴纸；标题、守关者和挑战入口保留清楚的层级。
- 入场 520ms，按 45ms + 55ms × 顺序错开。聚焦放大 2.3%、上浮 3px，转正并以刚度 260 / 阻尼 22 的弹簧落稳；没有持续晃动正文。
- 按压只把卡面和场景预览横向扩张 2.2%、纵向压缩 5.5%，文本在独立绘制层保持等比。松开有阻尼回弹；使用不超过 1/120 秒的积分步长，避免不同帧率下震荡发散。
- 墨团由指针位置扩张，进入 430ms、离开 280ms。正文过渡时增加临时对比描边；挑战按钮根据背景亮度选择深字或浅字，避免两者交叉渐变时一起变灰。
- 独立外框以刚度 320 / 阻尼 30 追随唯一焦点；鼠标进入卡片会同步原生键盘焦点。支持方向键、Tab、Enter，以及 Esc 返回。
- 松开确认先回弹 130ms，再接常驻墨水转场；选择只执行一次。覆盖前按 Esc 可取消排队的选关，覆盖后屏蔽重复输入；地图节点移除会自动取消其延迟 Tween。
- 从战斗返回地图会暂停战斗；关闭地图后仍停在同一暂停状态。减少动效时取消卡片弹性、压缩、入场和转场等待，保留静态焦点及信息。

## 尺寸与验证

沿用 1280×800 参考画布，整屏等比适配。每张卡片 558×240，返回入口 172×59；960×600 窗口下返回入口约 129×44，卡片仍超过 400×170。小角度、聚焦放大和外框均留在安全边距内。

专项检查：`--bridge-check --route-jelly-test`，结果 `prototype/artifacts/route-jelly-checks.txt`。原生 GPU 图像检查：`--bridge-check --route-jelly-review`。检查覆盖原生焦点、确认按住/释放、回弹、重复激活、覆盖前取消、暂停保留、两个实际窗口尺寸、减少动效和存档隔离。

`tools/render_route_jelly_film.py` 录制真实 Godot 界面、焦点与确认输入，输出 60fps 静音动效演示。`果冻地图试玩（不保存）.cmd` 使用隔离档案启动选关地图；新界面同样已进入默认游戏入口，正在运行的旧进程需要重新启动后才加载。
