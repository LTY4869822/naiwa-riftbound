## 角色形象纠正

重构中曾尝试以几何体制作临时奶蛙立体模型，比例和关节偏离原图，网格还出现部分背面剔除；用户指出变形、难看后，**该角色模型已撤下，相关奶蛙模型代码已删除**。

当前玩家直接使用原仓库 `idle.png`，头部、身体、配色来自原始像素。`naiwa_visual.gd` 和 `naiwa.gdshader` 只在运行时对腿、手掌和身体前倾做幅度受限的网格运动，所有动作连续过渡。落脚阶段固定脚底高度，图片基准线按原图可见脚底 y=351 处理；不再按各帧包围盒重新居中，也不使用旧四帧生成图。

这仍是受限的 2D 动作样片，不是已经制作完成的高质量逐帧跑步/格斗动作集。原图不能无损变出被遮挡的关节和全新出拳姿态；后续完整动作应以保持奶蛙身份的分层资产或有许可的原模型制作。本轮没有再把另一个近似角色作为替代品。

敌人采用独立 `enemy_rig.gd` 的连续关节模型，与玩家形象路径分开，避免再次错误复用。

## 启动与操作

- `启动奶蛙原型.cmd`：启动原版设计的桌宠；右键或托盘菜单进入游戏。
- `进入奶蛙游戏.cmd`：启动桌宠宿主并打开游戏；已有会话时继续。
- 游戏右上角“桌宠”或 P：回到桌宠，保留当前游戏会话。
- A/D 或方向键：移动；空格：跳跃；J：按节奏衔接两次掌击与终结踢击；K：直接重击，消耗体力；L/Shift：闪避，消耗体力；U：Lv.2 后用 60 专注释放冲击；Tab：营地/战斗；Esc：暂停。
- 营地选择虚拟碎片后喂食；等级、经验、背包继续使用原有存档。进入第二节时回复 25 生命，喂食每份回复少量生命。
- 完全退出可使用桌宠菜单“退出奶蛙”。关闭游戏窗口也会让桌宠恢复，当前战斗会话结束；已获得成长保留。

## 实现边界

`references/Naiwa` 保留只读参考；`desktop/source/Naiwa.cs` 由 `prepare_native_desktop.py` 从原始源码生成最小修改版，单独的 `GameBridge.cs` 管理游戏。编译使用 Windows 自带 .NET Framework C# 编译器：

```powershell
& './desktop/build.ps1'
```

桥接只访问 `%LOCALAPPDATA%/NaiwaDesktopPet/game-sessions/<会话>/` 下的 command、state 和心跳文件。角色存档继续由游戏唯一写入 `%APPDATA%/NaiwaFragmentPrototype/profile.json`。桌宠没有第二个成长写入器。

当前未安装 Shoto、LimboAI、Beehave 或 Statecharts 插件；本次依据前轮已核实的招式分阶段、行为选择等结构自行实现小范围样片，避免一次叠加多个框架。官方参考与许可证据见 [GitHub 调研](GITHUB_REBUILD_RESEARCH.md)。
