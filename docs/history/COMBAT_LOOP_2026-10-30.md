# 连战、战利品与招式重做 · 2026-10-30

> 后续版本：[裂界荒神](RIFT_2026-10-30.md) 已扩展首领血量、六招与三阶段，并新增精准闪避反击、关间遗物。本页保留上一轮实现与验证记录。

默认入口仍为 `prototype/v6/slice.tscn`。双击 **试玩连战新版.cmd**，以 Lv.5、0 魔能开始隔离试玩；金币、装备、成长和魔能都不会写入正式存档。正式入口 **进入奶蛙游戏.cmd** 使用同一份玩法代码。

## 这次的完整循环

选择地图 → 第一段战斗与首领 → 拾取金币、药露 → 从右侧通路进入第二段 → 第三段异兽首领 → 地图结算。

每张地图的三段共用同一个玩家实体，保留生命、体力、专注与魔能。段间没有胜利菜单，不会重建主角或自动回满血；以 0.55 秒遮罩过渡进入下一间场景。这是相连的三个战斗区域，尚非一张横向卷轴大地图。第三段结束才点亮整张地图的通关标记，三段分别保留首通/重游金币记录。

普通敌人死亡会抛出 8/10/12 金币，首领掉落 40 金币。走近才吸附、拾取和记账，不在击杀瞬间直接加钱；未拾取的金币不会跨区域自动领取。每段全部战斗结束会出现一瓶药露，拾取回复 **一半缺失生命**，例如上限 124、现有 48，回复到 86；满血不会消耗药露。取消了旧的每波 +30 生命以及换关满血。

金币与现有皮肤商城共用钱包。新增装备工坊，购买即装备，最多三阶：

| 装备 | 每阶效果 | 一 / 二 / 三阶价格 |
|---|---|---|
| 雷纹腕甲 | 攻击 +3 | 180 / 300 / 480 |
| 苔光护符 | 最大生命 +16 | 160 / 280 / 440 |
| 逐风足环 | 每秒体力回复 +3 | 150 / 260 / 420 |

增加生命上限不会补当前生命。营地、暂停与战斗 HUD 可进入工坊，再继续原来的旅程。皮肤仍等待用户提供素材，不给预留皮肤开放收费。新增掉落账本和装备等级兼容旧钱包；重复领取不会加钱，保存失败会回滚，实体金币保留并重试。

## 觉醒与操作

- 普通击杀 **5** 魔能，首领 **10**，重击/三连终段首次命中额外 **1**；满 **100** 按 **R** 觉醒。变身期间不继续积能，取消变身回血。
- 觉醒持续 **14 秒**，常规攻击为 **1.45 倍**。**U** 释放紫霆·灭界，三个接触为基础攻击的 **1.6 / 2.4 / 4.0 倍**，随后退形；健康的后期首领会存活，需要继续战斗。变身与终结演出仍有短暂无敌。
- 变身重新制作 8 个逐渐长出岩甲的完整姿势；开头和结尾采用互斥的噪声显现遮罩，连续改变等比身高。跑动与攻击不再整图叠化，消除双头/双手重影；脚底按测量锚点对齐。变身后为 8 跑姿、8 战斗姿势，命中帧对应实际生效窗口。
- 普通移动速度 **175 → 285**，觉醒移动 **215 → 310**。转向在输入首帧改变，常规加速 5600、反向加速 8400，实测检查在 100ms 内完成加速/换向。
- 三连时长改为 **0.38 / 0.44 / 0.56 秒**；接触结束后可通过移动取消收招，反方向优先；闪避采样当前输入方向，修复同一帧按右与闪避仍向左的问题。受击硬直缩短为 0.22 秒。

A/D 移动、空格跳跃、J 连击、K 重击、L/Shift 闪避、U 奥义、R 觉醒、E 交互、Tab 营地、Esc 暂停、P 桌宠。现有改键设置继续适用。隔离试玩 **F1～F4** 可观察四只后期首领的真实招式，不补魔能；新版启动脚本不提供 F6 补能。

## 首领招式

八只首领各有四种常规招式，距离参与选招，避免连续同招；低血量保留强化阶段，另有原本的专属奥义。近战、突进、远程、领域有各自的动作和特效。

| 首领 | 连击 | 突进 | 远程 | 领域 |
|---|---|---|---|---|
| 古树守卫 | 双枝横扫 | 古木冲撞 | 飞叶三连 | 根牢追击 |
| 荧冠菌王 | 菌冠二连掌 | 孢雾突进 | 散射孢弹 | 菌群召来 |
| 雷翼君王 | 双翼回旋斩 | 掠空突袭 | 三重风羽 | 雷印追猎 |
| 熔炉巨像 | 熔锤二连 | 炉心撞击 | 陨火投掷 | 余烬封路 |
| 裂岳·狰 | 五尾连鞭 | 裂岳跃扑 | 碎岩飞刃 | 崩山追柱 |
| 幽烛·烛阴 | 双生蛇噬 | 盘蛇横掠 | 烛目贯夜 | 夜蚀召来 |
| 天罚·应龙 | 龙翼连斩 | 破云飞掠 | 天息贯雷 | 雷狱追猎 |
| 吞焰·狍鸮 | 裂牙连噬 | 撼地扑杀 | 吞焰陨火 | 踏炉震波 |

常规蓄力约 0.54–0.92 秒、收招 0.38 秒，保留反击窗口。奥义增加异兽投影，配合落雷、岩爪、日蚀、巨口，以及元素弹幕或横向贯穿光束。领域落点避开施法者身体；弹幕按蓄力时的目标和朝向释放，不能穿过自己向背后临时追踪。光束显示地面危险带，可跳过。冲撞有效碰撞覆盖实际突进过程，修复到达玩家之前伤害窗口已经结束的问题。伤害不依赖粒子，领域会随施法者死亡取消。没有新增固定安全区。

## 素材与实现

新角色图集位于 `prototype/assets/loop-v2/`，由内置 imagegen 按用户提供的双角、黑岩巨爪、紫色裂纹形象生成。三张原始 RGBA 图未改绘；提示词与源文件见 `production.json`，完整 alpha 轮廓、脚底锚点和 SHA256 见 `manifest.json`。`prepare_loop_assets.py` 只读取 alpha 测量区域与锚点，不修改像素。

新增 `loop/` 包含连战/掉落、装备、首领招式与特效、变身显现着色器。继续使用项目已集成的画布和素材，来源见 `prototype/CREDITS.md`；本轮没有提取商业游戏的角色或特效。
