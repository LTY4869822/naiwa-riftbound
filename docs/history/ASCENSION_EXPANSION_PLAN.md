# 十二境与魔神觉醒：实施约束

用户提供的黄身、白腹、绿眼、黑岩巨爪、紫色裂纹、双角和破布腰围为觉醒形态的身份依据。四地图各三关，共十二关；每关都有首领，第三关引入山海经灵感的原创异兽。保留无固定安全区、定向攻击与危险落点预警。

实现目标：

- 四地图入口直接选择1/2/3关；原四关ID仍是各地图第一关，通关记录与货币不丢失，新关独立结算。
- 普通击杀积18点魔神力量，首领35点；100点按R觉醒。力量持久化且同一敌人不重复计数，试玩不写正式数据。
- 变身经历聚能、裂纹显现、岩甲/巨爪成形、完成与收势；脚底锚点不跳变，完整等比角色图，不拉伸身体。
- 觉醒约25秒，普攻/重击增强；按U释放“紫霆·灭界”，分段命中与终结爆发，消耗本次觉醒后自然退形。
- 原创压轴首领：森林“裂岳·狰”、洞窟“幽烛·烛阴”、风城“天罚·应龙”、熔炉“吞焰·狍鸮”。每只含两类常规招式和独立大招；狰/应龙/狍鸮各八个完整姿势，烛阴采用四姿势映射八个状态槽，避免初版图集边界干扰。
- 紫雷、空间裂痕、巨爪、冲击与黑岩碎片分层；伤害由游戏逻辑统一结算。特效数量受限，暂停/顿帧冻结，死亡/切图取消残留攻击。
- 保存每套图的提示词、工具来源、Alpha/尺寸、锚点与SHA；真实GPU检查衔接、规模、清晰度，再录制演示。

开源调研：Godot Asset Library 的 Stylized 2D VFX Lite（MIT）、VFX 2D Free（CC BY 4.0）是基础火花/爆炸方案；本轮角色专属紫雷巨爪与异兽奥义采用原创图集和现有项目渲染模块实现，不照搬商业游戏素材。调研链接及具体复用范围在交付说明中记录。
