# 苔光遗境 · 战斗 HUD

2026-10-28，已接入正式启动入口使用的 `prototype/v5/slice.tscn`。

## 美术与信息层次

菜单延续此前的活力墨水风；进入苔光遗境后，战斗仪表采用与场景相配的柔光奇幻风。暖金细框、翡翠生命、青白专注与玫瑰铜首领条构成统一的材料层次。参考 Hades 和 Hollow Knight 的信息组织方法，图标与边框全部原生绘制，未导入其他游戏的 UI 美术。官方参考及实际查看范围见 [HUD_ART_DIRECTION.md](HUD_ART_DIRECTION.md)。

- **左上伙伴仪表**：正面头像勋章、等级、当前/最大生命、分段生命槽与细体力条。数字位置固定，受伤不会被填充遮住。生命填充快速更新，灰铜损血段稍作停留后跟上；实际生命末端有明亮切口。
- **真实状态**：生命不超过30%显示心形警示与「生命危急」，并有低频的局部边缘呼吸。短暂无敌保护、体力不足使用对应形状和文字，不添加未实现的中毒/护盾等状态。
- **底中技能仪表**：J连击、K重击、L闪避、U碎片冲击各有独立金属细线纹章与按键。可用、资源不足、施放、锁定和闪避冷却由真实状态驱动。专注数值仍以100为上限，环形仪表在60点达到可施放状态。
- **首领仪表**：只有真实存活的古树守卫出现时才显示。名称、叶冠、玫瑰铜生命槽与迟滞损血段居中排列，状态句区分蓄力、攻击、破势和观察时机；短句有轻暗承托面，避免融入明亮背景。
- **地点与辅助信息**：上中显示地点/波次，右上保留紧凑的暂停和桌宠按钮，底右显示实际碎片库存和升级经验。长提示移到独立消息区，技能栏与地面不被大面板覆盖。普通敌人受伤后的小血条也改为同色系细框。

所有区域通过原生 Control 分别锚定左上、上中、右上、底中和底角；沿用项目已有的保比例缩放。没有更改角色形象、战斗伤害、移动速度或成长规则。

## 状态绑定

`battle_hud.gd` 接受 host 推送的状态快照，显示动画只读取缓存，不直接轮询角色对象。已有 `player.changed`、成长事件和新增的敌人状态/受伤通知推动刷新；消息消退由既有游戏时钟推进。

可用性与实际战斗规则一致：

- K需要28体力，且遵守不同连击段的恢复窗口，没有虚构的独立冷却。
- L需要32体力，实际冷却0.55秒，施放/攻击窗口限制与角色脚本一致。
- U需要Lv.2、至少60专注，受击和正在施放时不可用。
- 减少动态开启后，取消生命拖尾与呼吸/涟漪，保留真实数值、状态文本及形状提示。

- `prototype/v5/battle_hud.gd`：仪表、资源动画、状态与布局。
- `prototype/v5/hud_glyphs.gd`：13类原生线条纹章。
- `prototype/v5/ui.gd`：正式战斗界面挂载与原有暂停菜单。
- `prototype/v5/main.gd`、`enemy.gd`：事件与状态快照；无战斗数值调整。
- `prototype/v5/effects.gd`：普通敌人细血条。
- `prototype/v5/hud_review.gd`：隔离检查与实机截图。
- `prototype/v5/hud_film.gd`、`tools/render_hud_film.py`：原生 GPU 状态演示录制。
