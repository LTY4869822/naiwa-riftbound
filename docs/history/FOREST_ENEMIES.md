# 森林敌人扩展 · 2026-10-28

当前默认的 `prototype/v6/slice.tscn` 已接入三种新敌人，保留现有侧身奶蛙、菜单、HUD与桌宠成长联动。V5兼容入口共用同一套敌人和遭遇数据。本轮没有重新制作玩家人物或修改正式档案结构。

## 三种敌人

| 敌人 | 形象与动作 | 攻击和应对 |
| --- | --- | --- |
| 荆背甲虫 | 苔绿叠叶甲壳、黄铜独角；行走、压角、冲撞、受击 | 0.82秒预警后，以440像素/秒冲撞0.43秒，命中23伤害；正面轻击减伤40%，重击或绕后可打断。冲撞后0.8秒硬直。 |
| 孢灯术士 | 紫褐菌盖、琥珀灯杖、树皮披衣；走路、举杖、蓄力、施法 | 1.05秒施法锁定开始时的位置，再显示0.48秒地面圆环；半径66、向上132像素的范围爆发21伤害。离开圆环、跳跃或闪避；击杀术士取消待爆发区域。 |
| 夜羽鸦 | 深蓝羽毛、白色面纹、青银翼尖；四姿扇翼、收翼、俯冲、刹停 | 0.78秒升空预警后，沿锁定路线俯冲，命中19伤害；随后恢复到可近战命中的低空。侧移或闪避，硬直时反击。 |

每种敌人一张8姿势透明图集，总计24个姿势。游戏通过图集动画、实际碰撞体位移和独立攻击状态驱动演出。每次攻击最多命中一次；闪避接触也消耗该次命中机会，保护结束后不会再次结算。暂停、返回营地、桌宠模式与命中停顿都会停止危险区域计时；重新开局或战斗结束清空所有危险区域。

## 四节路线

1. 苔径巡游：两名苔甲猎手、一只灯蛾。
2. 荆棘孢林：荆背甲虫、孢灯术士、苔甲猎手。
3. 夜羽回廊：夜羽鸦、荆背甲虫、灯蛾。
4. 古树守卫：原首领与孢灯术士。

同场2–3个敌人，同时最多两个敌人发动攻击，术士/灯蛾发起远程攻击时采用更严格的攻击预算。节间恢复30生命，上限按共享等级计算。HUD显示对应章节标题和四颗进度标记。完成全部四节后才会结算胜利。正面护甲减伤也反映在实际飘字中。

## 美术、特效和来源

- 三种新敌人由内置image_gen制作；原始PNG未重绘或重新缩放。提示词、源路径、SHA256和图集UV位于 `prototype/assets/enemies-expansion/generation.json`、`sprites.json`。图集使用等比缩放、运行时AtlasTexture采样和逐帧锚点。工具只读取alpha定位完整形体，不修改源图。
- 粒子来自 [Kenney Particle Pack](https://kenney.nl/assets/particle-pack)，CC0 1.0。使用官方透明PNG包中的7张纹理；原许可证、每张SHA256与下载包摘要在 `prototype/assets/enemies-expansion/vfx/`。原包保留于 `references/vfx/kenney-particle-pack.zip`。
- 参考 [GDQuest的Godot VFX教程](https://www.gdquest.com/news/2020/05/godot-vfx-secrets-out/) 中的纹理分层、蓄力、拖尾和冲击波方法，未复制其项目源码。冲撞角光、尘土、破甲火花、菌杖聚能、孢爆、羽刃和羽毛拖尾由本项目脚本编排。
- 橙色用于危险预警。甲虫用暖金/土色，术士用紫金，夜羽鸦用青银；玩家原有拳风和大招保持原表现。

## 打开与查看

- 正式游玩：`进入奶蛙游戏.cmd`，继续使用桌宠和正式共享成长；从第一节开始，第二、三节遇到新敌人。
- 直接试看：`试玩森林新敌人.cmd`，直接面对三种新敌人，Lv.3；标题标明隔离试玩，不写正式存档或处理真实投喂记录。
- 录像：`prototype/artifacts/enemy-demo.mp4`，296帧，30fps，9.87秒。使用真实Godot渲染和敌人攻击状态；为看清演出，示范中的玩家固定位置并启用保护。这不是自动通关录像。
