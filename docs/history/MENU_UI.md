# 奶蛙定制菜单 V2

2026-10-28。按用户对第一版的反馈重做，当前默认游戏入口仍为 `prototype/v5/slice.tscn`。

## 这次改了什么

第一版的平面奶黄/深绿对开构图、斜切按钮与侧面站姿已撤下。现在采用用户指定 [INKWAVE](https://github.com/amiaoapp/inkwave) 的菜单组织：全屏游戏场景、左侧菜单、右上档案、右侧角色展示与招式卡。

- 标题：深墨粗描边、厚投影、双色液态墨斑、副标题胶贴、组缩放弹入与逐字微动。
- 按钮：厚圆角、深色底和投影；主入口显著更大，补给入口为动态紫色网点；其余菜单略微倾斜。
- 聚焦：从鼠标入点扩张的不规则液体填充；按钮弹簧转正、放大，独立酸绿/深墨描边跟随当前按钮；图标同步转动。按下压缩后恢复。
- 切页：约320ms有机墨团覆盖、遮挡中只调用一次真实操作、约420ms墨洞扩散揭开；双色液体边与飞溅随遮罩运动。busy期间阻止重复操作。
- 场景：沿用本游戏苔光遗境，加入很轻的视差、景深遮罩、萤光和墨水展示台。菜单保留背景空间，文字始终稳定。
- 角色：按用户提供的三视图生成的正面站姿和正面捧腹反应姿势。正面站姿不是将旧侧面图水平翻转，也不是旧图放大裁切。
- 动作：点击角色或「逗它笑」播放原版422帧、30FPS、14.0667秒大笑和原声，保留转身、捧腹、笑倒，结束后恢复正面待机。重复触发不会叠播。
- 补给、成长、设置、暂停与原有战斗、桌宠往返仍接在原逻辑上。减少动态关闭漂浮、墨迹切页和战斗震动；原生焦点仍然可见。

这次忠实复现上述布局与核心交互动效，并不声称复制了参考项目所有页面、三维世界或全部特效。没有把参考作品的角色、商标或英文Logo放进奶蛙游戏。参考的源码参数、SHA和移植边界见 [MENU_V2_REFERENCE.md](MENU_V2_REFERENCE.md)。

## 角色来源和朝向

正面PNG由内置 imagegen 按用户提供的三视图参考重绘，角色比例、绿眼、细嘴、奶白肚子和黄肤作为约束；细节仍存在轻微重绘差异。两张资产的提示、源文件和透明度检查见 `prototype/assets/menu-v2/pet/FRONT_ASSET_PROVENANCE.md`。

完整大笑直接来自既有桌宠 `desktop/素材.nwp` 和笑声文件，保留来源许可、完整序列与SHA记录。原片包含转身和笑倒，因此不是全程严格正面；不会把正面单张反应图冒充完整正面动画。播放器采用原始时序、固定源画布比例和脚底对齐，最多缓存16帧，避免把动作做成几张图片的快速循环。

## 操作

↑/↓选择、Enter确认、Esc从子页返回、P返回桌宠。可点击奶蛙或「逗它笑」播放动作。补给卡片选择后显示真实总XP，未选择时喂食禁用。继续巡游复用同一战斗角色与会话。

双击 `file-feeder/进入奶蛙游戏.cmd` 使用菜单；已在运行的旧游戏窗口需要先保存关闭后重新打开，才能重新加载代码。
