# 玩法与数值

以下描述对应当前仓库源码，后续平衡调整以源码为准。

## 成长的三条账

| 资源 | 来源 | 用途 | 持久性 |
| --- | --- | --- | --- |
| 经验/等级 | 有效回收字节、游戏内补给 | 基础血量与攻击、成长解锁条件 | 本机档案/浏览器档案 |
| 金币 | 敌人掉落、关卡奖励 | 装备升级、后续皮肤 | Wardrobe账本 |
| 魔能 | 击杀与战斗事件 | 觉醒 | 独立Ascension账本 |

不要将“吞掉多少MiB”“当前有多少金币”和“觉醒还差多少魔能”合并成一个数。

## 回收经验

Profile默认每8×1024×1024字节兑换1XP，余数保留。等级L升到L+1需要60+(L−1)×30XP。

| 升级 | 所需XP | 仅靠回收时的该级需求 |
| --- | --- | --- |
| Lv.1 → Lv.2 | 60 | 480MiB |
| Lv.2 → Lv.3 | 90 | 720MiB |
| Lv.3 → Lv.4 | 120 | 960MiB |

这是每一级额外所需量，不是累计总量。计量是文件体积而非进程占用内存。收据、文件标识和余数共同记录，防止相同回执被重复入账。

Profile基础攻击为24+(等级−1)×7，再加装备；基础生命为100+(等级−1)×12，再加装备。Boss有自己的压力与等级补偿，所以升级不等于能无视后续招式。

## 连战

每图三段关卡依次推进。清理波次与守关Boss后，前两段会出现遗物选择、药露和向右继续的通路。跨段不直接恢复满生命。

三段小兵数量6、9、13；同图三种小兵逐步加入，技能层级为1、2、3。配置层面的生命倍率为1.0/1.22/1.42，伤害倍率1.0/1.10/1.22；实战还叠加类型、Boss阶段、玩家等级和其他压力逻辑，不能只用这两个表计算最终伤害。

## 基本动作

- J普攻：有起手、有效和恢复阶段，使用输入缓冲连接后续动作。
- K重击：消耗与恢复成本不同，用于破势、失衡压力和抓住空隙。
- L/Shift闪避：受体力与冷却约束，不是无限无敌。
- Space二段跳：空中再按一次，落地补充；使用当前跳跃余量UI确认。
- U星核巨拳：消耗专注，命中后触发专属反馈。觉醒期间的U按强化形态逻辑执行。

## 魔神觉醒

魔能上限100。普通敌人默认贡献5、Boss默认10，部分战斗事件可额外补充。R在满足地面和动作状态条件时消耗满槽，进入点燃、强化、终结/消散等阶段。

强化持续时间常量当前为14秒。形态的视觉、动作与真正造成伤害的触点分开管理，特效播放本身不代表每一帧都造成一次伤害。觉醒可以提供爆发窗口，但不会把整个地图永久变成自动秒杀模式。

## 遗物

| 遗物 | 主要作用 |
| --- | --- |
| 裂甲之牙 | 攻击与重击破势方向 |
| 追风羽印 | 闪避消耗/冷却方向 |
| 紫霆回响 | 精准闪避和反击方向 |
| 灵泉之心 | 关尾恢复方向 |

实际三选一的组合由当前地图和段落决定。确认才领取；焦点预览不产生奖励。效果在本次地图旅程内保留。

## 金币与药露

金币落地后靠近拾取，进入防重复计入的金币账本。药露在仍有缺失生命时回复，其默认公式为：

回复量 = 当前缺失生命 × 0.50，向整数取整并限制到最大生命。

灵泉遗物可提高该比例，当前上限0.80。拾取有各自声音和光点，满血时不会把无效恢复当作真实治疗。

## 装备和皮肤

装备工坊使用金币锻造，装备等级影响Profile读取的加成。皮肤配置在wardrobe/catalog.gd：当前原初皮肤已发布，reserved-01/02/03是未发布预留项。

未来皮肤需要同时提供预览、战斗动作清单和桌宠动作清单，并配置等级/回收字节或金币价格；资源齐备并标记发布后，才允许装备。不要只填一个标题和价格就对外宣称该皮肤已上线。

## Boss与打击感

AI根据距离、运动、是否在空中以及玩家攻击状态对候选招式评分，并参考最近招式历史。生命阶段解锁更多招式。预警、攻击有效期和恢复期是判断时机的依据。

PixelFX负责画面爆点，实际伤害由战斗系统确认。空挥不生成目标命中；群体命中对声画脉冲进行合并，避免同一帧叠加过多声音与屏幕震动。
