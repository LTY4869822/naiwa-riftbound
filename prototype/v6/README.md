# V6 侧身完整帧动作样片

2026-10-28 已作为 `project.godot` 默认入口。保留 V5 现有菜单视觉、战斗HUD和桌宠互动资源；通过子类把本版游戏补给页接回虚拟卡片。

角色基准为用户确认的 `../../art-source/character-standard/side-guard-01/naiwa-side-guard-review-01.png`。18张完整人物图包含8张备战/双拳、8张侧向移动、1张受击和1张腾空。旧正面攻击、旧分肢网格与旧3D替代角色均未被本版动作表引用。

- `naiwa.gd` 直接切换完整Sprite2D，固定统一缩放0.175；没有分肢、非等比缩放或光流变形。朝向反转整套人物。
- `assets/v6/side-frames.json` 由 `../../tools/build_side_runtime.py` 从真实alpha轮廓测量整体脚底锚点，站地姿势的支撑脚对齐平台。次要脚和空中脚的阴影按源图位置绘制。
- 两拳判定和特效由各自的拳头位置驱动；去掉了正面版本跨身体补偿的拳风。停步有短收势，攻击可立即中断视觉收势。
- `menu.gd` 继承V5菜单，保留完整大笑与设置，用分页虚拟碎片卡片完成补给。原生LIN4RUN桌宠源码、程序和文件处理入口未被本轮修改。
- `main.gd` 保留当前LIN4RUN进入/最小化返回/继续同进程的桥接接口。

验证、来源、操作与限制见 `../../docs/REBUILD_V6.md`。当前步态为8帧循环；受击和腾空各只有一张主要姿势，重击/大招复用拳势，仍是可继续打磨的样片。
